学校自习室预约系统 —— 桌面版使用说明
========================================

【这是什么】
这是一个免安装的 Windows 桌面程序，双击 exe 即可启动完整的自习室预约系统，
浏览器会自动打开操作界面，无需额外安装 Python 或任何依赖。

【如何使用】
1. 双击「自习室预约系统.exe」。
2. 稍等 3–5 秒，会自动弹出一个【独立窗口】（不是浏览器标签页，
   没有地址栏和标签栏，看起来就像普通桌面软件）。
3. 在窗口中注册学生账号，或直接用管理员登录：
   管理员账号：默认账号密码见 app\backend\db.py，首次部署请先自行修改
4. 使用完毕后，关闭弹出的黑色控制台窗口即可停止服务。

【目录结构】
自习室预约系统.exe　　← 双击运行
app\　　　　　　　　　 ← 系统程序（后端+前端+数据库，请勿删除）
runtime\　　　　　　　 ← 内置 Python 运行时（请勿删除）

【注意事项】
· 程序使用端口 8000，请确保该端口未被其他程序占用。
· 如果浏览器没有自动打开，手动访问 http://127.0.0.1:8000/ 即可。
· 关闭控制台窗口即停止服务；下次使用重新双击 exe 即可。
· 数据保存在 app\data\ 目录下，删除该文件可重置所有数据。
· 将整个文件夹复制到其他 Windows 电脑上即可直接使用（无需安装 Python）。

【常见问题】
Q：双击后没反应？
A：请稍等几秒；如果仍无反应，检查端口 8000 是否被占用（关闭占用程序后重试）。

Q：浏览器没自动打开？
A：手动在浏览器地址栏输入 http://127.0.0.1:8000/

Q：想重置数据？
A：删除 app\data\ 下的 .db 文件，重新双击 exe 即可自动重建演示数据。
